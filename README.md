# Novaclean - Сайт компанії

Сучасний, адаптивний веб-сайт для компанії Novaclean з красивими ефектами та анімаціями.

## Особливості

- ✨ Сучасний дизайн з градієнтами та анімаціями
- 📱 Повністю адаптивний для мобільних пристроїв
- 🎯 Плавні анімації та переходи
- 🌐 Українська мова
- ⚡ Швидка робота та оптимізація
- 🎨 Інтерактивні елементи

## Структура проекту

```
novaclean/
├── index.html          # Головна сторінка
├── about.html          # Про нас
├── products.html       # Продукція
├── services.html       # Послуги
├── contact.html        # Контакти
├── css/
│   └── style.css      # Основні стилі
├── js/
│   └── main.js        # JavaScript функціонал
└── README.md          # Документація
```

## Як використовувати

1. Відкрийте `index.html` у браузері
2. Або запустіть локальний сервер:
   ```bash
   # Python 3
   python -m http.server 8000
   
   # Node.js (якщо встановлено http-server)
   npx http-server
   ```
3. Відкрийте браузер і перейдіть на `http://localhost:8000`

## Налаштування

### Зміна кольорів
Відредагуйте CSS змінні в `css/style.css`:
```css
:root {
    --primary-color: #2563eb;
    --secondary-color: #10b981;
    --accent-color: #f59e0b;
    /* ... */
}
```

### Додавання контенту
Всі тексти на українській мові вже додані. Просто відредагуйте HTML файли для зміни контенту.

### Додавання зображень
Замініть placeholder елементи на реальні зображення:
```html
<div class="product-placeholder"></div>
<!-- Замініть на -->
<img src="path/to/image.jpg" alt="Опис">
```
