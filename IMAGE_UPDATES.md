# Оновлення зображень продуктів

## Поточний стан

Зображення для карток продуктів на головній сторінці потребують оновлення для кращої відповідності тематиці:

### 1. NovaClean IND (Професійна лінійка)
**Поточна тема:** Промислове чищення
**Потрібна тема:** Виробнича лінія м'ясокомбінату

**Рекомендовані зображення:**
- М'ясопереробне виробництво
- Конвеєрна лінія м'ясокомбінату
- Промислове обладнання для обробки м'яса

### 2. NovaClean HRC (Хорека)
**Поточна тема:** Ресторанна кухня
**Потрібна тема:** Промислова кухня

**Рекомендовані зображення:**
- Велика комерційна кухня
- Промислове кухонне обладнання
- Ресторанна кухня з великим обладнанням

### 3. Комбікормова промисловість
**Поточна тема:** Зерно/поля
**Потрібна тема:** Завод комбікормів

**Рекомендовані зображення:**
- Комбікормовий завод
- Виробництво комбікормів
- Промислове обладнання для виробництва кормів

## Як оновити

Замініть URL зображень в `index.html` на рядках:
- 133: NovaClean IND
- 147: NovaClean HRC  
- 161: Комбікормова промисловість

Приклад:
```html
<img src="https://images.unsplash.com/photo-NEW_ID?w=800&h=600&fit=crop" 
     alt="Опис" 
     loading="lazy">
```

## Альтернатива

Якщо потрібно використовувати локальні зображення:
1. Завантажте зображення в `images/products/`
2. Оновіть шляхи в HTML
