# Зображення для сайту Novaclean

## Структура папок

```
images/
├── clients/          # Логотипи клієнтів
├── products/         # Зображення продуктів
├── about/            # Зображення для сторінки "Про нас"
└── hero/             # Зображення для hero секції
```

## Поточні зображення

Наразі зображення завантажуються з Unsplash через URL. Якщо потрібно використовувати локальні файли:

1. Завантажте зображення в відповідні папки
2. Оновіть шляхи в HTML файлах

## Рекомендації

- Формат: JPG або PNG
- Розмір: оптимізовані для веб (до 500KB)
- Роздільність: мінімум 800x600px для продуктів
- Стиль: професійні, ясні, пов'язані з тематикою

## Заміна зображень

Замініть URL в HTML на локальні шляхи:
```html
<!-- Було -->
<img src="https://images.unsplash.com/..." alt="...">

<!-- Стало -->
<img src="images/products/product-1.jpg" alt="...">
```
