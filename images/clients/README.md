# Логотипи клієнтів

Ця папка призначена для зберігання логотипів компаній-клієнтів.

## Поточні логотипи (використовуються через URL)

Наразі логотипи завантажуються з офіційних сайтів компаній через URL. Якщо потрібно використовувати локальні файли, завантажте логотипи в цю папку та оновіть шляхи в `index.html`.

## Структура файлів

```
images/clients/
├── mhp-logo.png          # МХП
├── globinsky-logo.png    # Глобинський м'ясокомбінат
├── puzyata-logo.png      # Пузата хата
├── kremenchug-logo.png   # Кременчуг М'ясо
└── domino-logo.png       # Домінос Піца
```

## Вимоги до логотипів

- Формат: PNG або SVG (прозорий фон)
- Розмір: рекомендовано 300x150px або більше
- Фон: прозорий (для кращого відображення)
- Стиль: логотип має бути чітким та читабельним

## Заміна на локальні файли

Якщо ви хочете використовувати локальні файли замість URL, замініть в `index.html`:

```html
<!-- Було -->
<img src="https://example.com/logo.png" alt="Company">

<!-- Стало -->
<img src="images/clients/company-logo.png" alt="Company">
```
