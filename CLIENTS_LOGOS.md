# Інструкції для додавання логотипів клієнтів

## Структура папок

Створіть папку `images/clients/` та розмістіть там логотипи:

```
novaclean/
└── images/
    └── clients/
        ├── mhp-logo.png
        ├── globinsky-logo.png
        ├── puzyata-logo.png
        ├── kremenchug-logo.png
        └── domino-logo.png
```

## Заміна placeholder на реальні логотипи

У файлі `index.html` знайдіть секцію "Наші клієнти" та замініть placeholder на реальні зображення:

### Приклад для МХП:

**Було:**
```html
<div class="client-logo-placeholder mhp-logo">МХП</div>
```

**Стало:**
```html
<img src="images/clients/mhp-logo.png" alt="МХП">
```

## Вимоги до логотипів

- Формат: PNG або SVG (прозорий фон)
- Розмір: рекомендовано 300x150px або більше
- Фон: прозорий (для кращого відображення)
- Стиль: логотип має бути чітким та читабельним
