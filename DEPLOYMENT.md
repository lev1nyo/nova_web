# Інструкція з розгортання сайту Novaclean

## Варіанти розгортання

### 1. GitHub Pages (Безкоштовно, найпростіше)

**Переваги:**
- Безкоштовно
- Просте налаштування
- Автоматичне оновлення при push
- Підтримка кастомних доменів

**Кроки:**

1. Перейдіть в репозиторій: https://github.com/lev1nyo/nova_web
2. Settings → Pages
3. У розділі "Source" виберіть:
   - Branch: `main`
   - Folder: `/ (root)`
4. Натисніть Save
5. Через кілька хвилин сайт буде доступний за адресою: `https://lev1nyo.github.io/nova_web/`

**Підключення кастомного домену:**
1. У Settings → Pages додайте ваш домен у поле "Custom domain"
2. Налаштуйте DNS записи у вашому доменному провайдері:
   - Тип: `A` записи
   - Значення: `185.199.108.153`, `185.199.109.153`, `185.199.110.153`, `185.199.111.153`
   - АБО
   - Тип: `CNAME`
   - Значення: `lev1nyo.github.io`

---

### 2. Netlify (Рекомендовано)

**Переваги:**
- Безкоштовний план
- Автоматичне розгортання з GitHub
- SSL сертифікат
- CDN
- Просте підключення домену

**Кроки:**

1. Зареєструйтесь на https://www.netlify.com
2. Натисніть "Add new site" → "Import an existing project"
3. Підключіть GitHub і виберіть репозиторій `nova_web`
4. Налаштування:
   - Build command: (залиште порожнім)
   - Publish directory: `/` (або залиште порожнім)
5. Натисніть "Deploy site"
6. Сайт буде доступний за адресою: `https://random-name.netlify.app`

**Підключення кастомного домену:**
1. У Netlify: Site settings → Domain management → Add custom domain
2. Введіть ваш домен
3. Налаштуйте DNS записи:
   - Тип: `A` записи
   - Значення: `75.2.60.5`
   - АБО
   - Тип: `CNAME`
   - Значення: `your-site.netlify.app`

---

### 3. Vercel

**Переваги:**
- Безкоштовний план
- Швидке розгортання
- Автоматичний SSL
- CDN

**Кроки:**

1. Зареєструйтесь на https://vercel.com
2. Натисніть "Add New Project"
3. Імпортуйте репозиторій `nova_web` з GitHub
4. Налаштування:
   - Framework Preset: Other
   - Build Command: (залиште порожнім)
   - Output Directory: `.`
5. Натисніть "Deploy"
6. Сайт буде доступний за адресою: `https://nova-web.vercel.app`

**Підключення кастомного домену:**
1. У Vercel: Settings → Domains → Add Domain
2. Введіть ваш домен
3. Налаштуйте DNS записи згідно інструкцій Vercel

---

### 4. Cloudflare Pages

**Переваги:**
- Безкоштовний план
- Швидкий CDN
- Автоматичний SSL
- Легке підключення домену (якщо домен на Cloudflare)

**Кроки:**

1. Зареєструйтесь на https://pages.cloudflare.com
2. Натисніть "Create a project"
3. Підключіть GitHub і виберіть репозиторій
4. Налаштування:
   - Framework preset: None
   - Build command: (залиште порожнім)
   - Build output directory: `/`
5. Натисніть "Save and Deploy"

---

## Налаштування DNS для кастомного домену

### Якщо домен на Cloudflare:
1. Додайте сайт в Cloudflare Pages
2. У налаштуваннях Pages додайте ваш домен
3. Cloudflare автоматично налаштує DNS записи

### Якщо домен на іншому провайдері:

**Для GitHub Pages:**
```
A записи:
@ → 185.199.108.153
@ → 185.199.109.153
@ → 185.199.110.153
@ → 185.199.111.153

CNAME:
www → lev1nyo.github.io
```

**Для Netlify:**
```
CNAME:
@ → your-site.netlify.app
www → your-site.netlify.app
```

**Для Vercel:**
```
CNAME:
@ → cname.vercel-dns.com
www → cname.vercel-dns.com
```

## Рекомендації

1. **Найпростіший варіант:** GitHub Pages (якщо домен вже є)
2. **Найкращий варіант:** Netlify (найпростіше підключення домену, автоматичне розгортання)
3. **Якщо домен на Cloudflare:** Cloudflare Pages (найшвидше)

---

## Після розгортання

1. Перевірте, що всі сторінки відкриваються
2. Перевірте мобільну версію
3. Налаштуйте SSL сертифікат (зазвичай автоматично)
4. Перевірте швидкість завантаження
5. Налаштуйте Google Analytics (за потреби)

---

## Оновлення сайту

Після змін у коді:
```bash
git add .
git commit -m "Опис змін"
git push origin main
```

Сайт автоматично оновиться на платформі розгортання.
